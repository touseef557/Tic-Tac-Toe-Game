# Tic Tac Toe Game

A console-based Tic Tac Toe game built in C++ using an object-oriented design.

##  Features
- Two-player gameplay on a 3x3 board
- Win detection (rows, columns, diagonals) and draw detection
- Score tracking across multiple rounds in a session
- Replay option after each round
- Input validation for invalid types and invalid moves
- Cross-platform screen clearing (Windows/Linux)

##  Tech Stack
- **Language:** C++
- **Concepts:** Object-Oriented Programming, Input Validation

##  How to Run
1. Clone this repository
2. Compile: `g++ TicTacToe.cpp -o TicTacToe`
3. Run: `./TicTacToe`
